### 我相信的几件事

**把方法论变成可执行的流程。** 出海不是靠运气，是把"怎么做"拆成 Agent 能跑的步骤。

**做出来比说出来有用。** 每个作品都是真实需求的副产品，用户量是最好的投票。

**AI 放大的是判断力。** 工具会写代码，但"做什么、不做什么"的决定还得人来做。
